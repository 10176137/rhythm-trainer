# 识谱辅助 v2 实现记录

日期：2026-10-21  
对应需求：`FRONTEND_SCORE_READING_REQUIREMENTS_v2.md`（Rhythm Trainer 前端识谱辅助需求 v2.0）

## 1. 范围与边界

这次改动覆盖**前端识谱渲染层、显示设置和简单 MusicXML 导入**：

- 默认练习乐谱是 4 小节 **C 大调钢琴练习曲**（右手 16 个四分音符、左手 8 个二分音符，
  72 BPM），由 `c-major-practice.musicxml` 经浏览器端解析器生成。原始两小节
  `rhythm-trainer-score-reading-example-v2.musicxml` 保留为 fixture 一致性测试与导入示例。
- 新增 `musicXmlParser.ts`：在浏览器端解析 `score-partwise` 的**简单子集**，支持单谱表/双谱表、
  G2/F4 谱号、音符/休止符/和弦/`backup`/`forward`、divisions、拍号、调号、显式变音记号与谱表外加线。
- **这不是完整 MusicXML 解析器**。未支持的多 part、非 G/F 谱号、复杂连音符/连音线、重复记号、
  装饰音、歌词/力度等会给出导入提示或直接拒绝，不会静默画错后继续判分。
- 没有修改 Rust 引擎、评分协议或 `PracticeConfig`；导入只改变前端 `ScoreDocument` 与练习目标来源，
  评分仍由引擎完成。

## 2. 谱面数据与谱表映射

`ScoreNote` 保存书写音高（`step/alter/octave`）、谱表、声部、小节与拍点，不保存屏幕坐标。
坐标由 `staffMapping.ts` 与 `scoreLayout.ts` 从记谱语义推导。

| 项目 | 高音谱表（右手） | 低音谱表（左手） |
| --- | --- | --- |
| 五线（下→上） | E4 G4 B4 D5 F5 | G2 B2 D3 F3 A3 |
| 五线 y（viewBox） | 140 126 112 98 84 | 308 294 280 266 252 |
| 线距 | 14 px | 14 px |
| 加线支持 | 上下各最多 3 条 | 上下各最多 3 条 |
| 自然音范围 | F3–E6 | E1–G4 |

C4–C5 的验收位置：

| 音 | y | 线上/间上 | 文字标记 |
| --- | --- | --- | --- |
| C4 | 154 | 加线（高音谱表下第 1 条） | 加线下 |
| D4 | 147 | 谱表下方、无加线（间） | 谱表下 |
| E4 | 140 | 第 1 线 | 线上 |
| F4 | 133 | 第 1 间 | 间上 |
| G4 | 126 | 第 2 线 | 线上 |
| A4 | 119 | 第 2 间 | 间上 |
| B4 | 112 | 第 3 线 | 线上 |
| C5 | 105 | 第 3 间 | 间上 |

| --- | --- | --- | --- |

标签位置规则：谱表内音符使用统一标注行；谱表下方音符的标签贴近音符下方；谱表上方音符的标签
放在音符上方（右手向左偏置、左手向右偏置），避开符干，避免高音标签被裁切或覆盖。高音谱表顶部
有高音时，viewBox 会自动增加上方留白；没有高音时不增加空白。

显式变音记号（`alter = ±1/±2`）会绘制 ♯/♭/𝄪/𝄫，音名与 MIDI 保持书写音高。超过双升/双降或
超过 3 条加线的音符仍按超范围处理。

## 3. MusicXML 导入

练习设置 → 乐谱来源中的操作：

- **导入 MusicXML**：选择 `.musicxml` / `.xml` 文件，浏览器解析后替换当前乐谱；可继续练习，
  目标时间线由导入音符重新生成。
- **谱表外示例**：载入内置单谱表单行示例，覆盖 C4/A3/F3（下方 1–3 条加线）与
  G5/A5/C6/E6/B5（上方间/加线）。
- **恢复默认乐谱**：回到 4 小节 C 大调钢琴练习曲。

支持的子集：

- `score-partwise`，只导入第一个 `part`（多 part 会提示）。
- 高音 G2 / 低音 F4 谱号；单谱表与双谱表。
- `divisions`、`time`、`key`、`staves`、`clef`。
- `note` / `rest` / `chord` / `backup` / `forward`，单声部与多声部按 MusicXML 游标推进。
- 四分/二分/全音符、八分/十六分（带符尾），显式 `alter` 与 `accidental`。
- 休止符参与时间游标但不绘制；tie/tuplet/grace 会给导入提示。

拒绝/提示：

- 非 `score-partwise`、没有 `part`/小节/音符、非 G2/F4 谱号会抛出可读的导入错误。
- 非四分音符拍号（如 6/8）按四分音符网格渲染并提示；复杂连音、连音线、多个 part 会提示。
- 超出加线范围/变音范围的音符仍由 `getUnsupportedNotes` 拦截，练习开始前会明确提示。

原始两小节 fixture 仍是手工转录；`scoreFixture.test.ts` 读取同目录 XML 校验 fixture 对应关系。
默认练习乐谱与导入路径由 `musicXmlParser.test.ts`、`practiceScore.ts` 和浏览器端 File 事件模拟验证。

## 4. 交互与显示开关

### 纯净谱面展示

- 默认关闭音名/线间标签，只显示谱面本身：当前目标列用绿色胶囊高亮，当前音符黑色，其余音符浅灰。
- 标题/副标题、拍号/调号/手别标签、`♩ = BPM`、扬声器试听、花括号、小节编号、左右手
  旋律/伴奏说明、阅读提示与展示目标脚注组成完整的展示层。
- 乐谱卡片使用全宽布局；反馈与输入卡片移动到乐谱下方，谱面获得更大的横向留白。
- 扬声器按钮用 Web Audio 播放当前目标音的短试听，只作用于用户点击手势，不参与评分。

### 音名提示

- 默认关闭，以保持纯净谱面；在「练习设置 → 识谱辅助」中开启。
- 严格判定档（`profile === 'strict'`）下关闭音名时，选中详情锁定为「音名提示已关闭」；
  标准模式点击音符仍可查看详情。
- 关闭时隐藏：谱面音名、`当前目标音` 名称、音高提示里的目标音名、SVG 的
  `aria-label/desc` 音名。
- 偏好保存在 localStorage：`rhythm-trainer.score-hints.v3`，设置面板可「跟随默认」清除覆盖。

### 线/间位置提示

- 默认关闭，可独立于音名开关。
- 线上音符使用深蓝、间上/加线区音符使用蓝色；颜色不是唯一信息通道：
  - 每个音符带「线上 / 间上 / 加线下 / 加线间下 / 加线上 / 加线间上 / 谱表下 / 谱表上」文字徽标；
  - 设置页说明只影响显示；
  - 音符的 `aria-label` 包含位置文字。
- 关闭时只移除叠加层与颜色，音符的 x/y、加线、音高、时值、小节位置不变。

### 选中音符与 MIDI

- 点击/键盘（Enter/Space）选中任意音符；详情显示音名、音区、谱表、线/间、虚拟键盘键位、时值、小节/拍。
- 详情右侧虚拟键盘 C2–B5 高亮对应键位。
- MIDI Note On/Off（设备或模拟键）与当前目标/选中音相同时显示绿色光环与 `MIDI 匹配` 徽标。

## 5. 评分边界

- `buildPracticePlan` 只接收乐谱、模式、手、循环范围，不接收任何显示提示参数。
- `layoutScore` 是纯几何函数，同样不接收提示开关；`buildScoreViewModel` 只给几何结果附加显示布尔值。
- 因此开关音名/线间提示不会改变 `ScoreDocument`、目标时间线、引擎 payload 或最终分数。
- 导入乐谱只替换前端乐谱来源；引擎仍只接收目标 atoms，评分权威不变。

## 8. 已知限制

- 不是完整 MusicXML 解析器：只导入第一个 part，只支持 G2/F4 谱号；重复/跳转记号、装饰音、
  连音线、复杂 tuplet、歌词、力度、调号图形、连桁等未完整支持。
- 休止符参与时间计算但不绘制；tie/tuplet/grace 仅提示并按近似方式渲染。
- 非 x/4 拍号按四分音符网格显示并提示。
- 引擎目标 atoms 仍按每个起音组 960 ticks 生成；左手全音符的时值评分语义不在本次改动范围内。
- 只支持 ±3 条加线、双升/双降；超出会阻止开始并提示。
- 截图是 `score-card` 区域视觉记录，不是全页面像素回归测试；未引入 Playwright 截图断言。
