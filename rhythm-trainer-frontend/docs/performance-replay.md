# 本地演奏重放

记录详情内的“重放我的演奏”读取实际 MIDI，不读取标准答案生成声音。
后端接口为 `GET /api/takes/:takeId/performance-replay`，文件放在引擎数据目录
`performance-replays/<takeId>.json`，同名 `.manifest.json` 永久关联 Take。
新记录在结算时保存；旧记录首次查看时从本地 trace 迁移。关联建立后，文件丢失或
损坏直接显示丢失，不自动重建或替换成标准曲谱。原始报告与逐音符复盘独立保留。

事件转换由 Node 负责：输入源、MIDI 通道、重复同音分别识别；保留起音、力度、
松键及 CC64 延音。暂停时切断声音并保留暂停间隔。重放不参与评分。
半踏板按开关处理，其他踏板不合成；缺少松键、踏板释放、截断 trace 均提示限制。
旧 Follow 记录通常只保存 Note On，不能从标准目标猜测松键时长；缺少原始事件时不可重放。
新的硬件 Follow 会保存 MIDI 事件，但其完成判定在最后目标 Note On，若最终松键未捕获，
重放会明确提示截断，不能声称是电钢琴原声录音。

音色在当前设备保存：采样大钢琴与柔和合成琴。采样来自 Alexander Holm 的
Salamander / Tone.js 分发，30 个本地 MP3（约 2 MB），不在播放时访问外网。
这是单力度层音库，通过实际 MIDI 力度控制响度与亮度，不是原始 16 力度层完整音库。
署名与许可见 `public/audio/salamander/ATTRIBUTION.txt`。播放音色也用于标准曲谱试听。

音频控制器复用暂停、恢复、停止与音频时钟，重放只做音频调度投影，不创建 Take。
界面关闭或换记录即停止；过期音色加载失败不能打断新的播放。
