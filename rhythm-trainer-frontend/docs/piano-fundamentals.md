# 钢琴基本功专项设计

## 选择依据

RCM 的技术训练分类包含音阶、和弦、琶音和其他音型。Eastman 的钢琴课程也包含五指音型、音阶、三和弦与琶音。这些项目可以编排为短谱，通过现有 MusicXML 导入、Rust 计划与 MIDI 评分链路练习。

- RCM：https://www.rcmusic.com/learning/about-the-royal-conservatory-certificate-program/curriculum-and-disciplines
- Eastman：https://www.esm.rochester.edu/classpiano/overview/
- 音阶参考指法：https://www.pianoscales.org/major.html
- 手指编号：https://www.pianoscales.org/fingerings.html

这里使用原创短音型，不复制考级曲目，也不声称等同于考级技术要求。跳进找键是根据键盘位置转换目标补充的练习。

## 训练内容与递进

| 项目 | 练习目的 | 三级内容 |
| --- | --- | --- |
| 五指练习 | 熟悉固定位置内五个相邻琴键，保持音符间隔 | 顺阶四分 → 间隔八分 → 顺阶与间隔交替 |
| 音阶上下行 | 熟悉调号、换指及回程 | 一八度四分 → 一八度八分 → 两八度八分 |
| 分解和弦 | 熟悉三和弦音的位置与伴奏音型 | 原位 → 转位 → 调内和弦的低高中高音型 |
| 三和弦齐奏 | 完整、同时弹出和弦音 | 原位 → 转位 → I–IV–V–I 连接 |
| 跨八度琶音 | 随音区移动，完成和弦音的跨八度路径 | 一八度四分 → 一八度八分 → 两八度八分 |
| 跳进找键 | 准确移动并落到下一个琴键 | 五度往返 → 八度往返 → 多落点交替 |

每项支持 C/G/F 大调、右手/左手/双手、40–140 BPM。初学从单手、一级、40–60 BPM 开始，一次改变一个变量。级别表示练习内容，由用户主动选择，不自动宣称掌握。

五指与音阶显示参考指法；左右手分别编号。谱表采用合适音区，必要时整体移低一八度，保留音程与指法，保证所有音符合现有启动范围检查；界面起点由生成结果提供。调号与谱面书写音高、MIDI 音高一致。

## 反馈边界

沿用现有报告：节奏由 Rust 内核判定，音高是独立反馈；和弦在同一拍点形成多个目标音，不展开为先后音符。指法只用于显示，不推断实际使用的手指。

MIDI 音符事件不能确认手型、手臂放松、抬指动作或真实音色。因此提供自查提示，不新增这些项目的分数。力度平衡、连奏/断奏专门评分、听觉训练留待具备相应观测和评估方式后设计。

## 实现与验证

- `skillDrillCatalog.ts`：内容分类、分级、指导语。
- `fundamentalDrills.ts`：基本功音型、调性、谱号、参考指法。
- `skillDrills.ts`：统一生成入口，兼容已有四类节奏练习。
- `SkillTrainingPage.tsx` / `SkillDrillPreview.tsx`：分类选择、当前项目说明、按需谱面预览。
- 预览与启动使用相同 MusicXML；不建立第二套评分逻辑。
- 对六项 × 三调 × 三手别 × 三级的 162 个组合检查严格导入、每声部拍数、谱面支持范围及手别作用域，另检查调号、齐奏起音与指法。
- 浏览器检查左手 F 大调音阶和双手 G 大调和弦启动、结束、保存报告后仍留在 `/training`。测试使用独立引擎、模拟 MIDI 和独立数据目录，不代表实体键盘演奏精度验证。

谱面检查同时修复了空 `direction` 缺少 `direction-type` 引起的第一小节缺音，并稳定了 OSMD 可选空数组参数，避免预览更新循环。
