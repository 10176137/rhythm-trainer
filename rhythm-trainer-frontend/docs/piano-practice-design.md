# 专项训练与基础测试

## 训练目标

按完整音型练习，不按随机 MIDI 音符凑时长。五指练习关注邻接落键与均匀性；音阶关注调性与位置移动；分解和弦、琶音关注和声形状与跨度；三和弦关注目标音齐全；节奏和双手项目关注时序与配合。谱面指法只是参考，不能证明演奏者使用了正确手指。

课程分类依据：

- [ABRSM Piano](https://www.abrsm.org/en-gb/piano)：技术练习、视奏与听觉属于不同能力，不以一项成绩代替全部钢琴水平。
- [RCM curriculum](https://www.rcmusic.com/learning/about-the-royal-conservatory-certificate-program/curriculum-and-disciplines)：技术内容包含音阶、和弦、琶音、音型与练习曲。
- [Yamaha technique practice](https://hub.yamaha.com/keyboards/k-how-to/tips-for-practicing-technique-part-1/)：使用音阶、琶音等材料，并变化节奏练习。

## 可执行的练习流程

- 定时：2、5、10 分钟目标，按完整乐句取整。每段约一分钟，段间保存并提供预备拍，避免 iPad 一次制谱数百小节。
- 连续：相同段落机制，直到使用者结束。保存失败、无输入或证据不足时停止接续，不自动跳过。
- 重复：第一个所选项目和调性；适合巩固动作。
- 随机：Node 在所选项目与调性范围内选择完整音型，段内避免立即重复同一组合。参考指法随编排保留。种子保存，允许复现。
- 配置偏好保存在本机，正式出题及校验在服务器；离开页面或停止接续会取消尚未生效的请求。

## 基础测试协议 piano-baseline-1

固定 60 BPM、标准档位、结束后反馈，无系统伴弹。右手五指 C、左手五指 C、右手音阶 G、左手琶音 C、右手和弦 F、双手配合，各四小节，共 96 秒音符时轴及预备拍。它是应用内基础技能基线，不是考级模拟或完整音乐能力认证，也不声称测到了陌生谱面的视奏能力。

每项呈现 Rust 最终报告中的 MATCH、WRONG_PITCH、MISSING、EXTRA 与匹配音起音绝对误差。音高正确率为正确音数除以目标音数与多余音数之和，漏音、错音、多余击键都会降低结果；节奏命中不冒充音高正确。95% 音高正确（含多余音惩罚）且平均起音误差不超过 60ms 是本应用公开的练习参考标准，不是来自考级机构的分数线。

## 证据与边界

评估仅接受已保存 Take ID；服务器验证练习谱快照完全一致、速度和模式一致，读取 Rust 规划与评分结果。未知、降级、低可信、无输入、未完成各项的演奏不生成能力结论。复测比较仅使用相同协议的既往有效记录。

连续计划只在已保存且可评估的本段结果后推进；下一段与剩余时长由服务器确定，同一 Take 重试不会重复扣减预算或多出下一段。前端只编排交互、等待、取消和结果展示。

没有 MIDI 能力分数可以替代真实指法、手腕放松、姿态或音色观察。先低速单手，逐渐加入调性变化及双手；参考结果确定下一次练习目标，再用相同测试复测。
