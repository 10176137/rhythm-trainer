# 专项训练与基础测试

## 训练目标

按完整音型练习，不按随机 MIDI 音符凑时长。五指练习关注邻接落键与均匀性；音阶关注调性与位置移动；分解和弦、琶音关注和声形状与跨度；三和弦关注目标音齐全；节奏和双手项目关注时序与配合。谱面指法只是参考，不能证明演奏者使用了正确手指。

课程分类依据：

- [ABRSM Piano](https://www.abrsm.org/en-gb/piano)：技术练习、视奏与听觉属于不同能力，不以一项成绩代替全部钢琴水平。
- [RCM curriculum](https://www.rcmusic.com/learning/about-the-royal-conservatory-certificate-program/curriculum-and-disciplines)：技术内容包含音阶、和弦、琶音、音型与练习曲。
- [Yamaha technique practice](https://hub.yamaha.com/keyboards/k-how-to/tips-for-practicing-technique-part-1/)：使用音阶、琶音等材料，并变化节奏练习。
- [Sight Reading Factory](https://www.sightreadingfactory.com/)：参考其公开说明中的难度约束维度（节奏、跳进、音域、变化音），没有使用其未公开的算法。
- [lacuna sight-reading generator](https://www.lacuna.fm/sight-reading-generator)：参考“限制一次训练的挑战范围”和“参数与种子复现同一乐句”的方式。

## 乐句生成 piano-phrase-1

Node 使用人工编排的完整动机及受限变换：先呈现基础音型，中段变化方向、出发音、节奏或休止位置，最后回到主音或主和弦，用延长音和终止小节线收束。入门四小节，普通与进阶八小节；训练计划通过多句组成约一分钟的段落。普通练转位及四分/八分节奏组合，进阶扩展音域；两八度音阶才引入附点八分与十六分的长短、短长节奏，不把这些节奏放进入门五指练习。

入门三和弦只用原位，四小节依次练两拍齐奏、四拍保持、休止前后的重新落键、主和弦四拍收束。三个变式改变第三小节的进入位置和时值，不随机增加和弦音。五指练习保持五指音域及参考指法；音阶和琶音保持完整往返，不截掉回程来凑时长。纯稳定拍点项目有意保留固定音及四分音符重复，避免把拍点训练变成找键训练。

大部分项目有三个完整变式，以种子和项目内轮次选择；同参数、种子及生成器版本复现同一谱面。“单项打磨”可点击“换一组乐句”，预览与开始仍使用同一个服务端响应。说明直接取自生成材料，实际起始音包含从高音出发的情形。

## 可执行的练习流程

- 定时：2、5、10 分钟目标，按完整乐句取整。每段约一分钟，计入预备拍并扣除暂停时间后，在完整谱段末尾自动请求结束；段间保存并提供预备拍，避免 iPad 一次制谱数百小节。
- 连续：相同段落机制，直到使用者结束。保存失败、无输入或证据不足时停止接续，不自动跳过。
- 重复：第一个所选项目和调性；适合巩固动作。
- 随机：Node 打乱所选项目与调性的组合，每轮先覆盖一遍再重新打乱，并避免相邻项目与调性组合重复；仅选一个组合时轮换其乐句变式。段间保存随机状态、未完成的组合及项目内轮次，接续不会重新抽签遗漏项目。节奏项目固定 C，不重复计作其他调性的覆盖。纯拍点练习保留有目的的重复。参考指法随编排保留。
- 配置偏好保存在本机，正式出题及校验在服务器；离开页面或停止接续会取消尚未生效的请求。

## 基础测试协议 piano-baseline-1

固定 60 BPM、标准档位、结束后反馈，无系统伴弹。右手五指 C、左手五指 C、右手音阶 G、左手琶音 C、右手和弦 F、双手配合，各四小节，共 96 秒音符时轴及预备拍。它是应用内基础技能基线，不是考级模拟或完整音乐能力认证，也不声称测到了陌生谱面的视奏能力。

该基线继续使用原固定材料，谱面 SHA-256 为 `b8aa2d5f3fd612cf2eed4a4d17ece2b5e32aed68d61515c7f694b2a03fea31eb`；练习生成策略的变更不会把新材料混入旧基线的历史比较。

每项呈现 Rust 最终报告中的 MATCH、WRONG_PITCH、MISSING、EXTRA 与匹配音起音绝对误差。音高正确率为正确音数除以目标音数与多余音数之和，漏音、错音、多余击键都会降低结果；节奏命中不冒充音高正确。95% 音高正确（含多余音惩罚）且平均起音误差不超过 60ms 是本应用公开的练习参考标准，不是来自考级机构的分数线。

## 证据与边界

固定判定线的绿色表示该起音组的目标音已在窗口内命中，且没有同窗口的多余输入；多按错音时整组显示红色。Node 只把 Rust 已识别的 EXTRA 关联到最近且窗口覆盖该输入的目标组，空隙中的额外按键保留在最终报告中，不涂改邻近和弦。颜色是起音反馈，按键时长仍在结束后评估。自由识谱逐个集齐目标音，不检查齐奏；错误输入会降低首次答对率与按键命中率，不能据此宣称和弦演奏合格。

评估仅接受已保存 Take ID；服务器验证练习谱快照完全一致、速度和模式一致，读取 Rust 规划与评分结果。未知、降级、低可信、含不确定音符配对、无输入、未完成各项的演奏不生成能力结论。基础测试还须核对引擎实际生效的结束后反馈及无辅助标记，不能只读取界面配置。评估记录携带规则版本；旧版本缓存会在读取时重算，同版本有效结果才进入复测比较。复测比较仅使用相同协议的既往有效记录。复练建议优先选择尚未稳定的项目；音高正确但起音偏差较大时，先练该项时间控制，不建议提速。

连续计划只在已保存且可评估的本段结果后推进；下一段与剩余时长由服务器确定，同一 Take 重试不会重复扣减预算或多出下一段。前端只编排交互、等待、取消和结果展示。

没有 MIDI 能力分数可以替代真实指法、手腕放松、姿态或音色观察。先低速单手，逐渐加入调性变化及双手；参考结果确定下一次练习目标，再用相同测试复测。
