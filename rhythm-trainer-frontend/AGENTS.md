# 前后端职责

- `src/` 负责页面、输入交互、请求状态、错误/重试、谱面渲染、动画与音频播放。可以做即时输入反馈和展示用检查；不能把浏览器计算当作最终成绩、诊断或训练建议。
- `server/` 负责业务参数的最终校验、训练目录、目标音与节奏编排、调性/指法/音区选择、识谱出题、复习材料、结果重放校验、薄弱项与升级建议、持久化。计时练习通过 Node 服务调用 Rust 计划与评分内核。
- Rust 内核是计时计划、判定、时值和评分的权威。保持既有版本、指纹、可信度与证据校验；不要在 React 中另建一套评分或诊断规则。
- `shared/` 放接口类型、音乐基础定义及必须共用的纯规则。共享自由识谱状态机用于前端即时反馈，最终统计仍由后端重放后返回；最终结果页面展示后端报告。
- 浏览器不得导入 `server/` 的运行时代码。训练生成服务不可用时显示错误和重试，不启用本地生成或本地评分作为降级。
- 训练预览和开始使用同一份后端返回的乐谱。参数变化时取消旧请求，过期响应不能启动练习。
- 纯显示排版留在前端，包括四小节网格、补空、缩放、滚动与高亮；显示补位不能进入语义文档、练习计划或评分输入。

# 验证

涉及业务规则或接口时增加后端及接口测试，保持前端/后端边界测试通过。运行相关测试，再运行 `npm test`、`npm run test:teaching` 和 `npm run build`；谱面改动另检查 `/osmd-measure-grid-contract.html`。
